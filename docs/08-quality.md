# 测试、验收与发布

## 已有检查

类型/组件检查（svelte-check）、MockRuntime 行为测试（Vitest）、生产构建（Vite）、格式检查（Prettier）。CI 复用 pnpm verify；没有伪造 native 构建或真实 Agent 测试。

当前行为测试覆盖：切换保留历史、持久事件顺序、取消幂等且无迟到写入、运行时禁止重复发送和切换、对话隔离、快照不可变、错误校验与取消订阅。

## 测试分层

| 层级       | 重点                                     | 引入时机               |
| ---------- | ---------------------------------------- | ---------------------- |
| 契约/单元  | 事件状态、取消、幂等、版本冲突、日期校验 | 对应功能实现时         |
| 适配器集成 | IPC、子进程异常、持久化、流式断开        | 替换 Mock 时           |
| 浏览器交互 | 输入、切换、键盘、长消息、窄屏           | 关键交互稳定后加自动化 |
| 桌面实机   | 宠物、窗口位置、DPI、托盘、退出清理      | S01 起                 |
| 外部协议   | probe、版本、resume/cancel、权限         | 每个 Connector         |
| 发布烟测   | 干净机器启动、卸载、升级、备份恢复       | 可分发版本前           |

重点测失败路径，而不是仅验证页面存在。真实服务测试用专用测试数据，不能依赖每次联网成功；默认测试不要求账号或密钥。

## 0.0.1 手动验收

1. 打开页面，确认明确写着模拟模式、刷新清空。
2. 发送中文消息，回复逐步出现；中文输入法选择候选字不会误发。
3. 回复中点击停止，再等待，内容不继续增加。
4. 切换 Claude Code，显示切换记录，旧消息和对话 ID 保持不变。
5. 创建新对话，新历史为空；返回旧对话仍可见旧历史。
6. 刷新后恢复初始状态，符合内存模式说明。
7. 检查空输入不可发送、长消息不横向撑破、键盘焦点可见。

## 性能与可观测性

目标值在 docs/01。性能测试记录硬件、构建模式、样本数和 p50/p95，不能从浏览器开发模式直接推断原生性能。每次运行日志带 conversationId/runId/requestId 与错误码；默认不记录正文、完整工具结果或密钥。日志轮转和保留期在 0.2 配置，初始建议 7 日可调整。

## 发布门槛

- 版本范围与已知问题说明准确，演示标签不混入真实功能声明。
- pnpm verify、原生构建、目标机器冒烟全部通过。
- 应用名称、identifier、图标、许可证、第三方依赖清单已确认。
- 密钥存储、日志脱敏、外部进程权限与清理验证完成。
- 数据迁移前自动备份，实际执行过恢复；升级失败不会破坏原数据。
- 安装包签名/更新签名按平台准备；未签名开发包明确区分。
- 第一个分发版本先手动更新；自动更新有验证和回滚方案后再开放。

回滚不只是安装旧程序：旧 schema 不支持新数据时先从升级前备份恢复，并向用户说明可能丢失升级后的新增数据。可先在副本上验证，不直接改唯一数据文件。
