# 依据、风险与待决策

## 来源

2026-10-06 已读取你引用的“ONE项目方案评估”。它作为产品意图和讨论背景，不能替代依赖版本与协议事实的验证。以下官方资料用于核对工程方向；接入具体提供方时仍需按当时版本重新检查。

| 来源                                                                                         | 本项目使用方式                                 |
| -------------------------------------------------------------------------------------------- | ---------------------------------------------- |
| [Svelte TypeScript](https://svelte.dev/docs/svelte/typescript)                               | Svelte 类型检查与 Vite 开发方式                |
| [Tauri 前置环境](https://tauri.app/start/prerequisites/)                                     | Windows C++、Rust、WebView2 依赖               |

## 风险登记

| 风险                    | 影响                       | 处理措施 / 触发点                          |
| ----------------------- | -------------------------- | ------------------------------------------ |
| 原生环境未完成          | 无法确认宠物和窗口行为     | S01 第一项实机验证，不能用网页截图替代     |
| 多窗口状态重复          | 串线、消息重复或丢失       | P02 先定权威状态和 revision 协议           |
| TS Runtime 无可分发形态 | 开发机可用，用户机器失败   | R02 干净机器打包实验                       |
| 外部 Agent 协议不一致   | resume/cancel/权限语义不同 | 能力探测、按适配器测试、限定支持范围       |
| 上下文投影失真          | 交接后误解任务             | 来源 seq、可编辑摘要、预算和失败回退       |
| 工具取消后副作用已发生  | 重试重复写入               | 幂等键、实际结果对账，撤销独立设计         |
| 时区/夏令时解析错误     | 日程时间不正确             | 显示绝对时间与 IANA 时区；歧义人工选择     |
| 范围不断膨胀            | 原型迟迟不可体验           | 用 0.1 演示脚本作为里程碑门槛              |
| 持久化迁移失败          | 私人数据损坏               | 事务、备份、恢复演练，禁止直接覆盖唯一副本 |
