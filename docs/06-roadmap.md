## 阶段 5 · 0.5 领域能力与扩展

1c 已经把日历/笔记拆成插件并给了第一个本地文件实现。这里剩下的是把它接到真实服务（Outlook / Google）→ 证明第二个提供方接入时本体与宠物 UI 零改动 → MCP 适配已有服务 → 权限审计 → 插件的安装/签名生命周期。每项实际出现再拆任务。不在现在承诺开放插件市场，也不承诺跨机器访问。

跨机器访问属于传输层决策（ADR-014 的重新评估条件），要带鉴权、TLS 与跨机权限边界，按独立任务评估，不混进这一串。
